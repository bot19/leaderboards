# Matches must have Sides of equal size

A Match can be 1v1, 2v2 or larger, but both Sides must have the same number of Participants. Uneven Matches such as 2v1 are not allowed. Averaging a Side's Ratings gives a meaningless expected Result when the Sides differ in size, and the Rating changes would no longer balance out, so Ratings across the Ladder would drift over time. If uneven games ever need recording, they should be unrated rather than handled with an invented handicap.
