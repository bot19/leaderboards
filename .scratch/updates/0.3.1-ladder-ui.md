### Top row

One row above the Ladder name, items separated by a `·` (`aria-hidden`, neutral-400):

```
[←]  ·  Pool  ·  [+👤 Invite]
```

1. **Back arrow** links to Home (`/`), `aria-label="Home"`.
2. **Game name** (`ladder.gameName`), small neutral text.
3. **Invite** is a small button with an icon (`IconUserPlus`) and the text "Invite". It copies the Share link and toasts, as **Copy Share link** does today. Show it only once the Share link has loaded, as today. The visible label is "Invite"; in code it stays the Share link (see `GLOSSARY.md`).

Below the row: the Ladder name as the `<h1>`. The Share link input, the separate Game name line and the Home link are removed. Top padding matches Home: `py-10` becomes `pt-5 pb-10`.

### Record a Match

- Removed from beside the tabs.
- Added to the side rail as the **last** button, after the avatar and Nav, on the Ladder page only: the food-friends primary round button with `IconPlus` and `aria-label="Record a Match"`. It opens the Record Match panel as the old button did (`record=open`).

### Tab counts

Each tab reads `<label> · <count>`, with the `· <count>` part at reduced opacity (`opacity-60`) so the label leads. The tab's accessible name includes the count ("Leaderboard, 12").

| Tab | Count | Source |
|---|---|---|
| Leaderboard | Ladder members on the Leaderboard (active, not Inactive) | `['leaderboard', ladderId]` |
| Matches | Every Match the tab lists, any status | `['matches', ladderId]` |
| Ladder members | Active Ladder members, both on the Leaderboard and Inactive. Left and Removed don't count | `['ladder-members', ladderId]` |

The counts need all three queries on page load, whichever tab is open. Reuse these query keys so the panels share the cache. A count shows nothing while its query loads or fails. At 300px the tabs wrap onto a second line rather than scrolling the page.

### Inactive section

On the Leaderboard tab, render the Inactive section (its heading and list) only when at least one Ladder member is Inactive. Hide it while loading too, so it never flashes "Nobody is Inactive."
