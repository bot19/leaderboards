# 0.3.3: Confirm impactful actions

**Version:** 0.3.3

**Status:** ready-for-agent

**Blocked by:** 0.3.2

**What to build:** Five buttons that change who is on a Ladder, what they can do, or which Matches count now ask for confirmation first. The pattern is the one **Delete Ladder** already uses: `window.confirm(message)`, and the action runs only when the User accepts. Cancelling changes nothing and shows no toast.

**food-friends reference:** `/Users/teex/Code/food-friends/src/components/nav/NavPanel.tsx`, `handleRemove`: `if (!window.confirm(REMOVE_CONFIRM)) return` before the mutation.

**Schema:** None.

### The five buttons

| Button | File | Message |
|---|---|---|
| **Leave Ladder** | `src/features/ladders/MembersPanel.tsx` | `Leave this Ladder? You can rejoin from its Share link.` |
| **Remove** | `src/features/ladders/MembersPanel.tsx` (`MemberAdminActions`) | `Remove {displayName} from this Ladder? Only an Admin can reinstate them.` |
| **Demote to Player** | `src/features/ladders/MembersPanel.tsx` (`MemberAdminActions`) | `Demote {displayName} to Player? They'll no longer be an Admin.` |
| **Void** | `src/features/matches/MatchHistory.tsx` | Confirmed Match: `Void this Match? Every Rating on this Ladder will be recalculated without it.` Pending Match: `Void this Match? It won't count toward any Rating.` |
| **Reject** | `src/features/matches/WaitingForYou.tsx` | `Reject this Match? It will be Voided and won't count toward any Rating.` |

- Put the messages in one pure module in `src/lib/`, one function per action, taking what the message needs (display name, Match status). Messages use glossary terms, sentence case and contractions.
- Gate inside the click handler, before `mutate` or the RPC call, exactly as **Delete Ladder** does. Leave **Delete Ladder**'s existing confirm as it is.
- No other buttons change. **Make Admin**, **Reinstate**, **Confirm** and **Sign out** stay unconfirmed.

- [ ] `package.json` version is `0.3.3`
- [ ] Each of the five buttons shows its message; accepting runs the action as before, cancelling runs nothing
- [ ] Remove and Demote name the Ladder member; Void's message matches the Match's status
- [ ] Unit tests for every message function; component tests that stub `window.confirm` and assert, for each of the five buttons, that cancel skips the action and accept runs it

**Out of scope:** A custom confirm dialog component; confirms on Make Admin, Reinstate, Confirm or Sign out; changing Delete Ladder's message.
