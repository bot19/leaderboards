# 0.3.2: Leaderboard podium

Implement this by following `docs/agents/build-docs.md`.

**Version:** 0.3.2

**Status:** resolved

**Blocked by:** 0.3.1

**What to build:** On the Ladder page's Leaderboard tab, the top three rows become a podium. Ranks 1, 2 and 3 show 🥇, 🥈 and 🥉 in place of the number, and each of those rows gets a tinted background instead of white. Rank 4 onwards stays as it is. This is a first try: the human will judge the colours at review.

**food-friends reference:** None. food-friends' `components/activity/LeaderboardList.tsx` has no podium.

**Schema:** None.

### Podium

| Rank | Shown instead of the number | Row background |
|---|---|---|
| 1 | 🥇 | `bg-amber-100` |
| 2 | 🥈 | `bg-slate-100` |
| 3 | 🥉 | `bg-orange-100` |
| 4+ | the number, unchanged | white, unchanged |

- Go by the row's `rank` value from the `leaderboard` view, not its position in the list. The view ranks by Rating, then display name, so ranks don't tie in practice.
- Keep the rank as text for screen readers: give the medal `role="img"` and an `aria-label` of `Rank 1`, `Rank 2` or `Rank 3`.
- The medal sits in the existing `w-6` rank column, so names stay aligned with rows 4+.
- Put the rank-to-medal-and-colour mapping in one pure function in `src/lib/` (returning nothing for rank 4+), so the colours can be tweaked in one place.
- Only the Leaderboard list changes. The Inactive list has no ranks.
