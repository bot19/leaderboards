**Schema:** None.

### `public/manifest.webmanifest` (new)

```json
{
  "id": "/",
  "name": "Leaderboards",
  "short_name": "Leaderboards",
  "description": "Elo Ladders for office games.",
  "start_url": "/",
  "scope": "/",
  "display": "standalone",
  "background_color": "#f5f5f5",
  "theme_color": "#f5f5f5"
}
```

`#f5f5f5` is Tailwind's `neutral-100`, the page background set on `html` in `src/index.css`. food-friends uses its own page colour (`#f5f5f4`); use this app's.

### `index.html`

Match food-friends' `<head>`, minus the favicon (this app has none yet):

- Viewport becomes `width=device-width, initial-scale=1.0, viewport-fit=cover`. This also switches on the `env(safe-area-inset-*)` padding the side rail and drawer already use.
- Add `<link rel="manifest" href="/manifest.webmanifest" />`.
- Add `<meta name="theme-color" content="#f5f5f5" />`.
- Add `apple-mobile-web-app-capable` (`yes`), `apple-mobile-web-app-status-bar-style` (`default`) and `apple-mobile-web-app-title` (`Leaderboards`).
- The `<title>` stays `Leaderboards`.

### Netlify

The manifest is a real file in `dist/`, so Netlify serves it before the SPA fallback, and the existing `/:route` rule already sends it `no-cache`. Confirm `pnpm build` copies it to `dist/manifest.webmanifest`. `netlify.toml` needs no change.
