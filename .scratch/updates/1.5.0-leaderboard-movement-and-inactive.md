# 1.5.0: Rank movement, Inactive on the Leaderboard, and a shorter Provisional badge

Implement this by following `docs/agents/build-docs.md`.

**Version:** 1.5.0

**Status:** resolved

**Blocked by:** 1.4.0, which changes the Leaderboard's name links and the member view this build touches.

**What to build:** Three changes to the Leaderboard tab on `/ladders/$ladderId` (`src/features/ladders/LeaderboardPanel.tsx`):

1. **Rank movement.** Each row shows how the Ladder's latest Confirmed Match moved that Ladder member's rank: a green up arrow with the number of places gained, or a red down arrow with the places lost.
2. **Inactive stays on the Leaderboard.** Inactive Ladder members keep their place and rank on the Leaderboard, dimmed and tagged `Inactive`, instead of sitting in a separate list underneath.
3. **Shorter badge.** The Provisional badge reads `New`.

**food-friends reference:** None. Follow this repo's own patterns: the Leaderboard rows and podium in `LeaderboardPanel.tsx`, the badge styling already used for Provisional, `opacity-60` for dimmed rows (as 1.1.0 dims Voided Match cards), and the green and red outcome classes 1.1.0 and 1.4.0 share.

**Schema:** One migration that replaces the `leaderboard` view. It stays read-only, with `security_invoker = true` and the same grants.

- **Who's on it:** every Joined Ladder member (`status = 'active'`), Inactive or not.
- **New `inactive` column:** `coalesce(last_match_at, joined_at) < now() - inactive_threshold_days`, the same test `inactive_ladder_members` uses today.
- **Rank:** across everyone on it, Inactive included, ordered `rating desc, display_name asc` as now. Medals follow rank, so an Inactive member in the top three keeps theirs.
- **New `rank_change integer` column:** previous rank minus current rank, so a positive number means they moved up. How it's worked out:
  - The **latest Confirmed Match** is the Ladder's last Confirmed Match in confirmation order (`confirmed_at asc, id asc`, the order Replay uses).
  - Each member's **previous Rating** is their `rating_before` in that Match if they took part, and their current Rating if they didn't.
  - The **previous rank** is the same `rank()` over previous Ratings, among the members who had joined before that Match was Confirmed (`joined_at <= confirmed_at`).
  - `rank_change` is null when the Ladder has no Confirmed Match, or the member joined after it.
- Drop the `inactive_ladder_members` view. Remove `listInactiveMembers` and its mocks, and move any integration tests that used it onto the `inactive` column.
- Regenerate `src/types/db.ts`. Add `inactive: boolean` and `rankChange: number | null` to `LeaderboardEntry`.

Voiding the latest Match triggers a Replay, and then the previous Confirmed Match becomes the latest. Movement is always read from the current rows, so no extra handling is needed.

### Leaderboard rows

- **One list.** Remove the separate Inactive section. Its rows now sit in the main list at their rank.
- **Movement:**
  - Shown just left of the Rating: `IconArrowUp` with `+n` in `text-green-700`, or `IconArrowDown` with `−n` in `text-red-700`. Icon size 14, `tabular-nums`.
  - `aria-label`: `Up 1 place`, `Down 2 places`.
  - Nothing is shown when `rankChange` is null or 0.
  - Use the outcome colours that 1.1.0 and 1.4.0 share. Don't redefine them.
- **Inactive:**
  - The whole row gets `opacity-60`, including any medal.
  - Add an `Inactive` badge, styled like the existing Provisional badge.
  - Inactive rows still show movement.
- **Badges:**
  - Provisional reads `New`, keeping the same styling.
  - Put the badge text in one place (for example `src/features/ladders/badges.ts`) so the Leaderboard, Members tab and member view all read from it.
  - A member can have both badges: `New` first, then `Inactive`.
  - Badges sit after the name and never wrap under it. The name truncates first.
- **Tab count:** the Leaderboard tab's count now includes Inactive members, because it comes from the same list.

### Member view (1.4.0)

- Inactive members now have a rank. Show it, and add the `Inactive` badge, instead of the word `Inactive` in place of the rank. Left and Removed members still show their status in place of a rank.
- Show the Provisional badge as `New`.

### Glossary

- **Leaderboard:** "A Ladder's Joined Ladder members, ordered by Rating. Inactive members stay on it, marked as Inactive."
- **Inactive:** replace "Shown apart from the Leaderboard" with "Stays on the Leaderboard at their rank, marked Inactive." Their Rating is still untouched.
- **Provisional:** add "Shown on screen as **New**." Keep _Avoid_ as it is, since Provisional stays the term in code and copy.
- Update the domain-expert line that defines the Leaderboard as excluding Inactive members.
- Add **Rank movement:** how many places a Ladder member's rank changed with the Ladder's latest Confirmed Match.
