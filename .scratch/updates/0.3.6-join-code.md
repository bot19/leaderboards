# 0.3.6: Join a Ladder by code

Implement this by following `docs/agents/build-docs.md`.

**Version:** 0.3.6

**Status:** ready-for-agent

**Blocked by:** 0.3.5

**What to build:** Every Ladder gets a short **Join code** (6 characters, like food-friends' friend code) that a User types into the app to join. On iPhone, a link tapped in Slack or Messages opens Safari, not the saved home-screen app, and Safari has its own signed-out session; a code keeps joining inside the app. The Share link stays and now carries the Join code (`/join/<code>`), so links and codes reach the same Ladder. Ladder previews become signed-in only.

**food-friends reference** (all paths under `/Users/teex/Code/food-friends/`):

| Take | From |
|---|---|
| Code format and generator: 6 characters from `123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ`, lookup with `upper(btrim(code))` | `docs/init-v2/schema-v2.sql` (`gen_friend_code`, `friend_code_owner`) and `src/lib/groupCode.ts` |
| Code input: mono, uppercase, `maxLength={6}`, placeholder in sans; states Checking…, found (with action button), unknown, error | `src/components/nav/NavAddFriends.tsx` |
| Debounced live lookup (300ms, idle until the format is valid) | `src/features/nav/useFriendCodeLookup.ts` |
| Code card: small uppercase label, code in `font-mono text-xl tracking-[0.2em]`, copy IconButton that flips to a check | `src/components/nav/NavFriendCode.tsx` |

**Schema:** One migration. The code **is** the Share link token: no new column, and `share_token` keeps its name.

- `private.gen_join_code()` returns 6 characters from the alphabet above.
- `create_ladder` uses it instead of `gen_random_uuid()::text`, retrying on a unique-violation collision.
- Backfill every existing Ladder with a fresh code. This invalidates every Share link sent so far; that's accepted, because no real Users exist yet.
- Add a check constraint: `share_token ~ '^[1-9A-Z]{6}$'`.
- `preview_ladder` and `join_ladder` match on `upper(btrim(p_share_token))`, so `fp7k2q` and ` FP7K2Q ` both work.
- `preview_ladder`: revoke `anon`, keeping `authenticated` only. `/join/$token` already requires sign-in, so nothing in the app loses access, and signed-out visitors can no longer guess codes.
- Update `supabase/seed.sql` so its Share link tokens are valid codes, and regenerate `src/types/db.ts` if signatures change.

### Glossary

Add **Join code** to `GLOSSARY.md` under People and membership: the 6-character code that identifies a Ladder for joining, typed in the app or carried in the Share link. _Avoid_: invite code, ladder code. In code, `share_token` remains the column name.

### Home: the Ladders section

- The section heading changes from **Your Ladders** to **Leaderboards** (copy only; in code these are still Ladders).
- Two right-aligned IconButtons on the heading row, in this order:
  1. **Join a Ladder**: `IconKey`, `aria-label="Join a Ladder"`
  2. **New Ladder**: the existing `IconPlus` from 0.3.0
- Each opens its form in the same place and the same way New Ladder does (between the heading and the list, divider below, input focused), and its icon flips to `IconX` while open. Opening one closes the other.
- The Join form: a "Join code" label, the food-friends code input, and the live lookup below it:
  - Checking… while the debounced lookup runs
  - Found: `<Ladder name> · <Game> · <n> Ladder members`, with a **Join** button (spinner inside while joining)
  - Unknown: `That code doesn't match a Ladder.`
  - Error: `Couldn't check that code. Try again.`
- Join calls `join_ladder` with the code, then goes to that Ladder's Leaderboard tab and refreshes the Ladder list. If the User is already an active member, go to the Ladder as well. A Removed Ladder member sees the function's refusal inline, as `/join/$token` shows it today.

### Ladder page: Invite

0.3.1's **Invite** button now toggles an inline invite card below the top row instead of copying straight away. The card is the food-friends code card:

- Label: `Join code`; helper text: `Share this code so colleagues can join.`
- The code, with a copy IconButton (check icon once copied)
- A small **Copy link** text button below that copies the Share link, with the existing toast
